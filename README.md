# copy.js
Simplest (No BS) core js drop in copy.js

# usage
## For Dev
### Step 1 – include JS
```
<script src="copy.js"></script>
```
### Step 2 – use <copy> tag
```
<p>
  <copy>My text or whatever</copy>
</p>

```
## For User
- On hover it will show copy link 
- On click of copy link it will copy to clipboard and show "copied" message
